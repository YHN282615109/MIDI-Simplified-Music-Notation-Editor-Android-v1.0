# MIDI简谱编辑器

[![license](https://img.shields.io/badge/license-AGPL--3.0-blue.svg)](LICENSE)
[![platform](https://img.shields.io/badge/platform-Android-brightgreen.svg)]()

《MIDI简谱编辑器》是一款基于 Android Studio 开发的音乐创作工具，旨在通过简洁的简谱语法实现多音轨音乐的编辑、播放与导出功能。该软件支持 16 音轨创作，可自定义乐器、速度和调式，适合音乐爱好者快速制作简单的音乐作品，尤其适合无专业音乐制作经验的用户使用。

## ✨ 软件特色

- **多音轨管理**：支持 16 个独立音轨，每个音轨可分配不同乐器和通道，音轨独立控制，可单独编辑或同时播放。
- **灵活的音乐控制**：支持自定义乐器（GM 标准 0–127）、速度（BPM）和调式（如 C 大调、G 大调等）。简谱支持高低音标记（`.` 低音，`'` 高音）和时值控制（`-` 延长）。
- **便捷创作功能**：内置随机谱曲工具，可自动生成音轨内容；支持循环播放、停止、全选/复制/删除等编辑辅助功能。
- **完整的工作流**：从简谱编辑、实时预览到 MIDI 导出一体化，多线程播放机制确保多音轨同步。

## 📱 使用方法

1. **选择音轨**：点击左侧“音轨1–16”按钮切换编辑轨道。
2. **编辑简谱**：在文本框中输入符合格式的简谱。
3. **播放控制**：点击“播放全部音轨”开始播放，可通过“停止”按钮控制。
4. **导出文件**：点击“导出 MIDI”按钮将当前编辑内容保存为 16 音轨 `.mid` 文件。

## 📝 简谱格式说明

### 头部信息
以 `[乐器编号,速度,调式]` 开头，例如 `[0,120,G大调]`

- **乐器编号**：0–127（遵循 GM 标准）
- **速度**：BPM 值（如 120 表示每分钟 120 拍）
- **调式**：支持 C 大调、G 大调、D 大调等

### 音符内容
由基本音符（1–7）、高低音标记（`.` `'`）和时值（`-`）组成：
- `1-7`：基本音符
- `.`：低音（跟在音符后）
- `'`：高音（跟在音符后）
- `-`：延长时值

### 示例
`[10,220,G大调]5-351'--76-1'-5---`

- 乐器编号 10（八音盒）
- 速度 220 BPM
- 调式 G 大调
- 后续为简谱旋律

## ⚙️ 编译与开发

- **开发语言**：Java
- **开发环境**：Android Studio
- **运行环境**：Android 5.0、Android 7.1.1 及以上
- **核心功能**：
  - 简谱解析与 MIDI 生成
  - 多音轨同步播放
  - 随机谱曲算法
  - MIDI 文件导出（标准 16 音轨格式）
